# Chronicle hierarchy concept

A visual proposal requested by the user: Story collection → Act/episode/chapter → Mission. Created using the built-in image generator and original Our Story concept as the style reference. Saved as chronicle-story-hierarchy.png. No website or backend code changed.

## Interaction proposal

1. Chronicle lists story collections in chronological order with separate Thya and Kihto progress summaries.
2. Selecting a collection shows its groups, using the appropriate label: act, episode or chapter. Breadcrumbs return to earlier levels.
3. Selecting a group shows missions and separate completion states for each character. Mission rows expand into character notes.

Green belongs to Thya and purple to Kihto. All completed tick symbols and circular borders must be green regardless of character or active theme; incomplete borders use the active theme. The generated concept contains some purple completion indicators: those are illustration imperfections, not a change to this rule.

All progress numbers, mission labels and locks are illustrative. Do not treat them as verified game structure, actual journal progress or proof that incomplete content is locked. Progress fractions should use matching units and full bars should mean full completion. Include every intervening season/expansion in the real catalogue rather than treating this condensed concept list as exhaustive.
